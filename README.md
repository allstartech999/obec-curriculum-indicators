# 🇹🇭 OBEC Curriculum Indicators JSON (มาตรฐานและตัวชี้วัด สพฐ.)

> ฐานข้อมูลเปิด (Open Data) รวบรวมมาตรฐานการเรียนรู้และตัวชี้วัดตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช 2551 (ฉบับปรับปรุง พ.ศ. 2560 และเกณฑ์ตัวชี้วัดระหว่างทาง/ตัวชี้วัดปลายทาง พ.ศ. 2566 ตามหนังสือ ศธ 04010/ว 1553) ในรูปแบบไฟล์ JSON ที่เป็นมาตรฐาน ครบถ้วน 100% ทุกกลุ่มสาระการเรียนรู้ ทั้งระดับประถมศึกษา (ป.1 - ป.6) และมัธยมศึกษา (ม.1 - ม.6)

## 📌 จุดประสงค์โครงการ (Objective)

ในปัจจุบัน ข้อมูลตัวชี้วัดและมาตรฐานการศึกษาของกระทรวงศึกษาธิการและ สพฐ. ส่วนใหญ่ถูกเผยแพร่อยู่ในรูปแบบไฟล์ **PDF** หรือ **Word** ทำให้ยากต่อการนำไปประมวลผลต่อในระบบสารสนเทศ, โปรแกรมจัดทำแผนการสอน, หรือระบบสมุดบันทึกผลการเรียนรู้ (เช่น SGS, SchoolMIS หรือ ปพ.5)

โครงการนี้มีเป้าหมายเพื่อ:
1. แปลงตัวชี้วัดทั้งหมดให้อยู่ในรูปแบบ **Machine-readable JSON** ที่เป็นมาตรฐาน ครบถ้วน 100%
2. ระบุการจำแนกประเภท **ตัวชี้วัดระหว่างทาง (BETWEEN)** และ **ตัวชี้วัดปลายทาง (FINAL)** ตามประกาศล่าสุดของ สพฐ. (2566 ตามหนังสือ ศธ 04010/ว 1553) อย่างถูกต้องแม่นยำ 100% ตรวจสอบเทียบกับตารางสรุปของ สพฐ. ทุกรายวิชา
3. สนับสนุน Open Education Data ให้นำไปใช้งานต่อได้ฟรีโดยไม่มีเงื่อนไขผูกมัด

## 🏷️ โครงสร้างฟิลด์ข้อมูล (Data Schema)

ทุกรายการตัวชี้วัดถูกจัดเก็บในโครงสร้างมาตรฐานเดียวกัน:

```json
{
  "code": "ว 1.1 ป.1/1",
  "name": "ระบุชื่อพืชและสัตว์ที่อาศัยอยู่บริเวณต่าง ๆ จากข้อมูลที่รวบรวมได้",
  "type": "BETWEEN",
  "subjectArea": "วิทยาศาสตร์และเทคโนโลยี",
  "gradeLevel": "ป.1",
  "strand": "สาระที่ 1 วิทยาศาสตร์ชีวภาพ"
}
```

### คำอธิบายฟิลด์ (Field Definitions)
* **`code`** (`string`): รหัสตัวชี้วัดตามมาตรฐาน สพฐ. เช่น `ค 1.1 ป.1/1`, `ว 4.2 ม.3/1`, `ส 2.1 ม.4-6/1`
* **`name`** (`string`): ข้อความระบุรายละเอียดและพฤติกรรมบ่งชี้ของตัวชี้วัด (ภาษาไทย)
* **`type`** (`"BETWEEN"` | `"FINAL"`):
  * `BETWEEN` = ตัวชี้วัดระหว่างทาง (ใช้สำหรับการจัดการเรียนรู้และประเมินผลระหว่างภาค)
  * `FINAL` = ตัวชี้วัดปลายทาง (ใช้สำหรับประเมินผลลัพธ์สุดท้ายเมื่อจบหน่วยการเรียนรู้/รายวิชา)
* **`subjectArea`** (`string`): กลุ่มสาระการเรียนรู้ (เช่น `คณิตศาสตร์`, `วิทยาศาสตร์และเทคโนโลยี`, `ภาษาไทย`)
* **`gradeLevel`** (`string`): ระดับชั้นปี (`ป.1` ถึง `ป.6`, `ม.1` ถึง `ม.3`, `ม.4-6`)
* **`strand`** (`string`): สาระการเรียนรู้ย่อย (เช่น `สาระที่ 1 จำนวนและพีชคณิต`, `สาระที่ 4 เทคโนโลยี`)

## 🚀 วิธีการใช้งาน (Getting Started)

### ติดตั้งผ่าน npm
```bash
npm install obec-curriculum-indicators
```

### เรียกใช้งานใน Node.js / TypeScript
```javascript
// ดึงข้อมูลทั้งหมด
const allIndicators = require('obec-curriculum-indicators/data/all-indicators.json');

// หรือดึงเฉพาะระดับชั้นและกลุ่มสาระที่ต้องการ
const mathP1 = require('obec-curriculum-indicators/data/math-p1.json');
const scienceM3 = require('obec-curriculum-indicators/data/science-m3.json');

// กรองเฉพาะตัวชี้วัดปลายทาง (FINAL)
const finalOutcomes = mathP1.filter(item => item.type === 'FINAL');
console.log(`จำนวนตัวชี้วัดปลายทาง ป.1: ${finalOutcomes.length}`);
```
