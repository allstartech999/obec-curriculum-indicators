## 📌 จุดประสงค์โครงการ (Objective)

ในปัจจุบัน ข้อมูลตัวชี้วัดและมาตรฐานการศึกษาของกระทรวงศึกษาธิการและ สพฐ. ส่วนใหญ่ถูกเผยแพร่อยู่ในรูปแบบไฟล์ **PDF** หรือ **Word** ทำให้ยากต่อการนำไปประมวลผลต่อในระบบสารสนเทศ, โปรแกรมจัดทำแผนการสอน, หรือระบบสมุดบันทึกผลการเรียนรู้ (เช่น SGS, SchoolMIS หรือ PP5)

โครงการนี้มีเป้าหมายเพื่อ:
1. แปลงตัวชี้วัดทั้งหมดให้อยู่ในรูปแบบ **Machine-readable JSON** ที่เป็นมาตรฐาน
2. ระบุการจำแนกประเภท **ตัวชี้วัดระหว่างทาง (BETWEEN)** และ **ตัวชี้วัดปลายทาง (FINAL)** ตามประกาศล่าสุดของ สพฐ. (2566) อย่างชัดเจน
3. สนับสนุน Open Education Data ให้นำไปใช้งานต่อได้ฟรีโดยไม่มีเงื่อนไขผูกมัด

## 📋 รูปแบบโครงสร้างข้อมูล (JSON Schema)

```typescript
interface StandardIndicator {
  code: string;         // รหัสตัวชี้วัดทางการ เช่น "ว 2.1 ม.2/1", "ท 1.1 ม.3/2"
  name: string;         // ข้อความตัวชี้วัดตามเอกสารหลักสูตรแกนกลาง
  type: 'BETWEEN' | 'FINAL'; // "BETWEEN" = ตัวชี้วัดระหว่างทาง | "FINAL" = ตัวชี้วัดปลายทาง
  subjectArea: string;  // กลุ่มสาระการเรียนรู้ เช่น "วิทยาศาสตร์และเทคโนโลยี"
  gradeLevel: string;   // ระดับชั้น เช่น "ม.1", "ม.2", "ม.3", "ม.4-6"
  strand?: string;      // สาระการเรียนรู้ เช่น "สาระที่ 2 วิทยาศาสตร์กายภาพ"
}
```

### ตัวอย่างข้อมูลใน JSON
```json
{
  "code": "ว 2.1 ม.2/1",
  "name": "อธิบายการแยกสารผสมโดยการระเหยแห้ง การตกผลึก การกลั่นอย่างง่าย โครมาโทกราฟีแบบกระดาษ การสกัดด้วยตัวทำละลาย โดยใช้หลักฐานเชิงประจักษ์",
  "type": "FINAL",
  "subjectArea": "วิทยาศาสตร์และเทคโนโลยี",
  "gradeLevel": "ม.2",
  "strand": "สาระที่ 2 วิทยาศาสตร์กายภาพ"
}
```

## 💻 วิธีการนำไปใช้งาน (Usage Examples)

### 1. ใช้งานผ่าน JavaScript / TypeScript
```javascript
import indicators from './data/science-m2.json';

// ค้นหาเฉพาะตัวชี้วัดปลายทาง
const finalIndicators = indicators.filter(item => item.type === 'FINAL');
console.log(finalIndicators);
```

### 2. โหลดผ่าน CDN (GitHub Raw)
สามารถดึงไฟล์ไปใช้ผ่าน frontend ได้โดยตรง:
```javascript
fetch('https://raw.githubusercontent.com/allstartech999/obec-curriculum-indicators/main/data/math-m1.json')
  .then(res => res.json())
  .then(data => console.log(data));
```
